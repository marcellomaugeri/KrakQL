# Scripts to reproduce results from the paper "KrakQL: LLM-Guided Blind Introspection of GraphQL Schemas" to appear in SSBSE 2025.

## Requirements
- Python3.11+

### Install requirements
```
python3 -m venv venv # Build virtual environment
source venv/bin/activate # Activate virtual environment
pip install -r requirements.txt
```

### RQ1
```
python3 rq1.py
```

### RQ2
```
python3 rq2.py
```

Read the paper for more details.
